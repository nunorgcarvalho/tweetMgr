tweetMgr Style guide Early Bird theme

Early Bird

The tweetMgr look: an original homage to early-2010s microblogging. Cloudy sky, glossy dark top bar, a white column joined to a pale-blue dashboard, small Helvetica, serif numerals, and gradient buttons. Everything on this page is built from css/theme.css; no logos or artwork are borrowed from any real service.

Color

All colors are CSS variables on :root. Blue is for links and the one primary action per view; red is reserved for going over the character limit.

Helvetica Neue with Arial as the fallback, set small and tight. Georgia is used only for numerals: the character counter and the stat row.

Buttons

Glossy gradients with a one-pixel highlight. Use one primary button per view. Quiet buttons are for per-tweet actions and stay hidden until you point at the tweet.

Character counter

Counts down, not up. Pale gray while there is room, dark red for the last 20 characters, bright red with a minus sign once over.

Tweets

A thread is a list of tweet cards tied together by a line of "string" running between the avatars. Over-limit tweets get a faint red wash, and the overflow can be marked and split off.
